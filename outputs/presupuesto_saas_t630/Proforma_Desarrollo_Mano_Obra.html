Alcance del trabajo

GUTT_SYSTEM corre hoy como un despliegue único para una sola cooperativa (server.js, base SQLGUTPATATE). Para atender diez empresas, cada una se despliega de forma aislada sobre el servidor de la proforma de infraestructura: aplicación propia, base de datos propia y su propio enlace de acceso — no comparten datos entre sí. Este alcance no depende de terminar el rediseño de esquema multi-tenant que ya existe en el repositorio (server.gutt_system.js y db/gutt_system, con CooperativaId, todavía sin desplegar); ese rediseño queda como una fase futura opcional, a emprender si el número de empresas o la carga lo justifican.
